## 🚀 About Me

Senior software engineer in Bengaluru, India. Ruby on Rails and React. Open to remote work.

I spend most of my time on the unglamorous half of Rails: upgrading applications that have drifted several major versions behind, replacing search and background-job infrastructure without taking anything offline, and getting deploys down to one command.

Currently at ClearStack, working on billing and data systems — file ingestion pipelines, permission-aware search, and containerised deployment across Rails, PostgreSQL and Oracle.

## 🔨 What I've Been Building

Work I've shipped that took more thought than it looks like it did:

- Migrated a production app from **Rails 5.2 → 8** and **Ruby 2.7 → 3.4** — four major versions, including the Zeitwerk autoloader change, the 3.0 keyword-argument separation, and Sprockets → Propshaft.
- Replaced **Sunspot + Solr with Meilisearch** — permission filters, background indexing, health checks, and reindex tooling that runs without search going dark.
- Moved background processing from **Resque to PostgreSQL-backed Solid Queue**, then onto **Docker + Kamal on ARM64** with health-checked workers and managed accessories.
- Built a **template-driven ingestion system** for CSV, XLSX, TXT and XML feeds, with automated collection from client file shares and failure flagging.

## 📦 Projects

**[itsanproblem](https://github.com/BhupendraNegi/itsanproblem)** — anonymous problem-sharing platform. React + TypeScript on a Rails API. The hard part is moderation without identity: you can't ban a user you can't recognise.

**[CompressKaro](https://github.com/BhupendraNegi/CompressKaro)** — PDF and image tools that run entirely in the browser. Nothing is ever uploaded, so browser memory is the whole budget and large files have to stream rather than load.

**[CronLens](https://github.com/BhupendraNegi/CronLens)** — cron expressions translated to plain English, with next-run times across time zones. The interesting part is daylight saving: a job set for 2:30 AM has a genuinely ambiguous answer twice a year.

**[HookView](https://github.com/BhupendraNegi/hookview)** — disposable webhook inbox. Mint a URL, point a service at it, watch requests land live. Everything expires after 24 hours.
